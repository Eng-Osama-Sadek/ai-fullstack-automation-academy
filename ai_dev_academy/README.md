## 📖 عن المنصة (About The Platform)

**منصة الاحتراف** هي بيئة تعليمية وتطبيقية متكاملة تهدف إلى جسر الفجوة بين تطوير التطبيقات والويب، وهندسة الأنظمة الخلفية (Backend Systems)، وبناء شبكات الأتمتة بالذكاء الاصطناعي (**AI Automation / LLM Workflows**). 

تعتمد المنصة على معمارية **Clean Architecture** لتقديم مراجعة فورية للأكواد، توليد التمارين، ومعالجة المهام غير المتزامنة بكفاءة عالية.

---

## 🌟 المميزات الرئيسية (Key Features)

- 📘 **مسارات تعليمية متكاملة:** تغطي تقنيات بناء الأنظمة الحديثة مثل `Python`, `FastAPI`, `JavaScript/TypeScript`, `React/Next.js`, `Flutter`, `Dart`, و `AI Prompt Engineering`.
- 🚀 **مساعد ذكي مدعوم بـ Gemini AI:** لشرح الأكواد، اكتشاف الأخطاء، وإعادة صياغتها وفق معايير **Clean Code & Production-Ready Standards**.
- 🧩 **مولد تمارين سيناريوهات واقعية:** إنشاء مسائل برمجية متقدمة وتفاعلية تتكيف مع المسار المختار.
- ⚙️ **نظام أتمتة وتصنيف التذاكر (Async Pipeline):** وحدة تجريبية تعتمد على `asyncio.Semaphore` للتحكم بالتزامن و `Tenacity` لإعادة المحاولة التلقائية عند وجود أعطال شبكية.
- 📄 **تصدير مستندات احترافي ثنائي اللغة:** تصدير الدروس والشروح إلى ملفات **Word (.docx)** و **PDF** مع معالجة كاملة ومثالية للغة العربية (RTL) باستخدام `ReportLab` و `PyBidi`.
- 🎨 **واجهة مطور احترافية (Developer-Friendly UI):** تصميم داكن عالي التباين متوافق مع الاتجاهين (RTL/LTR) ومزود بتمييز الأكواد البرمجية (Syntax Highlighting).

## 🛠️ تقنيات المنصة (Tech Stack)

- **AI Core:** Google Gemini AI API (Advanced Prompt Engineering & Structured JSON Output).
- **Backend & Logic:** Python 3.11+, FastAPI, Pydantic v2, Asyncio, Tenacity.
- **Frontend & UI:** Streamlit (Custom Dark Blue & Cyan/Yellow Developer Theme with CSS Overrides).
- **Document Processing:** `ReportLab`, `Python-Docx`, `Arabic-Reshaper`, `PyBidi`.
